elm-watch playground

Program types

  • Html
  • Browser.sandbox
  • Browser.element
  • Browser.document
  • Browser.application
  • Platform.worker

Special cases

  • Hostile – page styles that try to break elm-watch’s browser UI
  • Many – several targets on one page
  • Frankenstein – several programs in one target
  • Typo – a typo in the init call
  • Web worker – a Platform.worker in a web worker
  • Web worker (ESM) – the same, but in a module web worker

Lots of targets

  • Generated – all the generated targets (see generate.js) on one page (start with --generated)

Open any page via cached.localhost to test hot reloading when the browser has cached the compiled Elm code.
